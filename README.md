# Kora

*Kora by Xtreme Cr8* — cloud-based, multi-tenant accounting, bookkeeping, payroll, and
e-invoicing SaaS platform for Nigerian businesses, built and operated by Xtreme Cr8tivity
Xpressions Limited.

This is a separate project from `xtreme-finance-system` (the internal, single-tenant tool
built earlier for Xtreme Cr8tivity's own use). Nothing here shares code with that repo — it's
the design and domain reference for this build, not a dependency.

**Status: public marketing homepage built. Tenant app, super-admin, and backend not started yet.**
